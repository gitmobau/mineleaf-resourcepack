# MINELEAF Resource Pack

Resource pack para el servidor MINELEAF.

## Packs

- [`aurora/`](aurora/README.md): resource pack Aurora para Minecraft Java 26.3 (zips en `aurora/dist/`).

## Mods

- [`mod/`](mod/README.md): **Aurora Guía**, mod de Fabric solo de cliente: yunque inteligente, lo que le falta a
  cada objeto y diario hardcore. No cambia ninguna mecánica.

## Referencia

- [`encantamientos/`](encantamientos/README.md): mecánicas de encantamientos, mesa y yunque en la 26.3, con calculadora de orden óptimo (`yunque.py`).
